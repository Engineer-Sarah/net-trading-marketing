
# Net Trading & Marketing

Official website of **Net Trading & Marketing**, serving businesses in Rawalpindi and Islamabad since 2000.

**Live site:** https://net-trading-marketing-fx7ppgk4d-khubaib7.vercel.app/

## About

A fast, responsive single-page website for a supplier of:

- General order supplies
- IT and networking
- Printing
- Power systems (UPS, batteries, solar)
- Security surveillance (CCTV, access control)

## Features

- Mobile-friendly layout with automatic dark mode
- One-tap Call, WhatsApp, SMS and Email buttons
- Appointment / enquiry form that sends the details to WhatsApp or email
- "Get a quote" links that preselect the service in the form
- Share button
- No build step and no dependencies, just one HTML file

## Project structure

```
index.html   # the whole website (HTML, CSS and JavaScript)
```

## Run locally

Open `index.html` in any browser.

## Deploy

Import this repository on [Vercel](https://vercel.com). No settings are needed; it deploys as a static site, and every push to `main` updates the live site.
