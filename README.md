# Net Trading & Marketing

Official website of **Net Trading & Marketing**, serving businesses in Rawalpindi and Islamabad.

**Live site:** https://net-trading-marketing-fx7ppgk4d-khubaib7.vercel.app/

## Features

- Responsive layout for mobile and desktop
- Product catalog with category filters
- Appointment / enquiry form that sends the details to WhatsApp or email (no server needed)
- One-tap Call, WhatsApp and Email links
- Floating WhatsApp button

## Project structure

```
index.html    # page markup
styles.css    # all styles
script.js     # catalog, animations, navigation
contact.js    # appointment / enquiry form (WhatsApp and email)
```

## Deploy

Import this repository on [Vercel](https://vercel.com). No settings are needed; it deploys as a static site.
